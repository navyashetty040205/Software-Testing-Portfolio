# Project Conclusion

This project applied software testing techniques to the SauceDemo online
shopping application. It includes a test plan, test case designs for
Equivalence Partitioning, Boundary Value Analysis, Decision Table Testing and
State Transition Testing, manual execution records, Selenium automation,
screenshots, and a defect report.

The recorded manual run reports 14 passed test cases. The separate automated
run on 2026-11-18 collected 57 tests: 56 passed and 1 failed. The failure
identified missing product images for the `problem_user` account and is
documented in [the defect report](04_Defect_Reports/Defect_Report.md).

The project demonstrates the testing workflow and identifies an observed
application issue; it should not be described as having no defects or as
achieving a 100% pass rate across all testing. The manual and automation
results are from separate runs and should be presented separately.
