# Project Conclusion

The project titled **Software Testing of an Online Shopping Application** was successfully carried out using the SauceDemo website.

The main objective was to understand and apply software testing concepts in a practical environment.

The following activities were completed:

1. Prepared a test plan for the application.
2. Identified important application modules and functionalities.
3. Designed test cases using Equivalence Partitioning, Boundary Value Analysis, Decision Table Testing and State Transition Testing.
4. Executed manual test scenarios for login, product selection, shopping cart and checkout.
5. Recorded actual results and documented the testing outcomes.
6. Created a defect report based on the executed test scenarios.
7. Developed a Selenium automation script using Python to test the login functionality.

The executed test scenarios produced the expected results, and no defects were observed in the tested scenarios.

This project helped develop practical knowledge of software testing techniques, test case design, test execution, defect documentation and browser automation.

Overall, the project provided valuable hands-on experience in the software testing process.
