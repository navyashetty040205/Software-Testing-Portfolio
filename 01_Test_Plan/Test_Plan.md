
# TEST PLAN

## 1. Introduction
This test plan describes the testing activities performed on the SauceDemo online shopping application. The purpose is to verify that the application functions correctly and meets the expected requirements.

## 2. Project Overview
- **Project Name:** Online Shopping Application Testing
- **Application Name:** SauceDemo
- **Application URL:** https://www.saucedemo.com/
- **Testing Type:** Functional Testing
- **Testing Approach:** Manual Testing and Automation Testing

## 3. Objectives of Testing
1. To verify the login functionality.
2. To test product browsing and selection.
3. To verify the add-to-cart functionality.
4. To test shopping cart operations.
5. To verify the checkout process.
6. To identify and report defects.
7. To verify the application using automation testing.

## 4. Scope of Testing

### In Scope
- User login and authentication
- Product display and selection
- Adding products to the cart
- Removing products from the cart
- Cart functionality
- Checkout information
- Order confirmation

### Out of Scope
- Real payment gateway integration
- Actual product delivery
- Third-party payment services
- Backend server security testing

## 5. Modules to be Tested

| Module | Functionality |
|---|---|
| Login | User authentication |
| Products | Product listing and selection |
| Shopping Cart | Add and remove products |
| Checkout | Enter customer information |
| Order Confirmation | Verify successful order placement |

## 6. Testing Techniques
The following testing techniques will be used:

1. Equivalence Partitioning
2. Boundary Value Analysis
3. Decision Table Testing
4. State Transition Testing

## 7. Testing Environment
- Operating System: Windows / macOS
- Browser: Google Chrome
- Testing Tool: Selenium WebDriver
- Programming Language: Python
- Platform: GitHub
- Application: SauceDemo

## 8. Test Deliverables
- Test Plan
- Test Case Documents
- Test Execution Report
- Defect Reports
- Automation Test Scripts
- Test Summary Report
- Screenshots

## 9. Entry Criteria
- Application is accessible.
- Testing environment is ready.
- Test scenarios and requirements are identified.

## 10. Exit Criteria
- All planned test cases have been executed.
- Actual results are documented.
- Identified defects are reported.
- Test execution summary is prepared.

## 11. Risks and Mitigation
| Risk | Mitigation |
|---|---|
| Website unavailable | Retry testing later |
| Browser compatibility issues | Test using an updated browser |
| Automation script failure | Verify locators and test environment |
| Unexpected application behaviour | Record and report defects |

## 12. Conclusion
This test plan provides a structured approach for testing the SauceDemo online shopping application. It helps ensure that all important modules are tested systematically and that defects are identified and documented.
